## 🎯 Study Strategies

### Spaced Repetition & Flashcards
- Use [KEY-TERMS-CHEATSHEET.md](KEY-TERMS-CHEATSHEET.md) to create digital or physical flashcards
- Review flashcards daily for 15-20 minutes
- Schedule reviews: Day 1, Day 3, Day 7, Day 14 (spaced repetition principle)
- Tools: Anki, Quizlet, or physical cards

### Mock Question Sets

**Beginner Set (Days 1-10)**
- What is an AI Agent?
- Explain RAG vs. fine-tuning
- What are LLM tokens?
- Basic system design: "Design a simple chatbot"

**Intermediate Set (Days 11-20)**
- Design a production RAG system
- Explain multi-agent architectures
- How would you evaluate LLM quality?
- Design cost-optimized AI inference

**Advanced Set (Days 21-30)**
- Design a multi-tenant AI platform
- Build a system for real-time agent collaboration
- Explain trade-offs in model selection
- Design a feedback loop for continuous improvement

### Hands-On Practice
- Build a simple RAG system locally
- Experiment with prompt engineering
- Create a multi-agent scenario
- Deploy a small model inference service

## 🚀 How to Use This Repo

### **For Agentic AI / LLM Engineer Roles**
1. **Week 1:** Start with foundational concepts in the AI Agents guide
2. **Week 2:** Review Gen AI Questions document for breadth
3. **Week 3:** Study LLM Interview Questions for depth
4. **Week 4:** Practice system design using the system design interview guide
5. **Ongoing:** Use [KEY-TERMS-CHEATSHEET.md](KEY-TERMS-CHEATSHEET.md) for daily flashcard review

### **For Backend / .NET Engineer Roles**
1. **Week 1:** Begin with C# language fundamentals
2. **Week 2:** Move to ASP.NET Core architecture and patterns
3. **Week 3:** Study authentication, authorization, and REST API design
4. **Week 4:** Deep-dive into Azure services and messaging systems
5. **Ongoing:** Use flashcards for terminology and patterns

### **For Full-Stack / AI Integration Roles**
1. Combine the AI and backend tracks alternating weeks
2. Focus on integration patterns between AI systems and backend services
3. Study deployment and scaling considerations
4. Practice end-to-end system design interviews

### **For Last-Minute Review**
- Use [KEY-TERMS-CHEATSHEET.md](KEY-TERMS-CHEATSHEET.md) for 30-minute review sessions
- Focus on definitions and one-liners for key concepts
- Perfect for the day-before refresher
